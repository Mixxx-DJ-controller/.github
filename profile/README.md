# Mixxx - Open Source DJ Mixing Software

## About Mixxx

Mixxx is an open source DJ mixing environment built for live performance, practice sessions, and library-driven set building. Mixxx focuses on flexible deck control, responsive cue handling, and a readable layout so performers can keep attention on the mix instead of the screen. Whether you are preparing a first set or maintaining a long-running residency, Mixxx keeps live mixing readable and predictable.

Mixxx live mixing workflows support tempo adjustment, beat matching, looping, and smooth transitions across genres and room sizes. Mixxx DJ controller integration lets you map hardware faders, jog wheels, and pads so gestures match muscle memory. Mixxx music library tools organize crates, playlists, and smart selections for quick recall during a set.

Because Mixxx is developed in the open, the project benefits from steady feedback and community contributions. That means features evolve around real performance needs rather than closed-roadmap guesses. For performers who want transparent tooling, Mixxx remains a practical and adaptable choice.

## Quick Start with Mixxx

1. **Open Mixxx** – Launch Mixxx and confirm audio output, sample rate, and the target library folder.
2. **Load tracks** – Bring files into the Mixxx music library and build a working playlist or crate.
3. **Map hardware** – Connect a Mixxx DJ controller or confirm keyboard mappings before performing.
4. **Run a short mix** – Practice Mixxx live mixing with two tracks, cue points, and a simple transition.
5. **Add effects** – Try Mixxx audio effects on a spare deck to confirm routing and intensity.
6. **Record and review** – Capture a short take and listen back to check Mixxx open source DJ settings.
7. **Rescan library** – Refresh the library after adding files to keep Mixxx music library views accurate.
